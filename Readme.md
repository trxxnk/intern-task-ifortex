# 🎓 Прогноз сдачи экзамена на основе поведенческих факторов

Этот проект представляет собой классификационную модель машинного обучения, предсказывающую, сдаст ли студент экзамен на основе анкетных данных. Модель обучается на дереве решений с использованием кросс-валидации и подбора гиперпараметров.

## 🗂 Структура проекта

- `main.py` — основная точка входа, запускающая процесс обучения и оценки модели.
- `utils.py` — функции загрузки, предобработки данных и подбора лучшей модели.
- `student_exam_data.csv` — пример входных данных в виде CSV-файла.
- `task_analys.ipynb` — файл-черновик для ознакомления с датасетом, его тестовой обработкой, а также поиск наиболее подходящей модели для решения задачи.

## 📊 Описание данных

Файл `student_exam_data.csv` содержит следующие признаки:

- `Сон накануне`: Да / Нет
- `Настроение`: Хорошее / Нормальное / Плохое
- `Энергетиков накануне`: 0 / 1 / 2-3 / 4+
- `Посещаемость занятий`: Высокая / Средняя / Низкая
- `Время подготовки`: За неделю / За несколько дней / Последняя ночь / Последний час
- `Сдал`: Да / Нет (целевой признак)

## 🚀 Как запустить

1. Установите зависимости (если ещё не установлены):

```bash
pip install -r requirements.txt
```

2. Запустите скрипт:

```bash
python main.py student_exam_data.csv
```

## 🧠 Что делает скрипт

1. Загружает и кодирует категориальные признаки.
2. Генерирует полиномиальные признаки степени 5.
3. Делит выборку на обучающую и тестовую.
4. Обучает дерево решений с подбором гиперпараметров через `GridSearchCV`.
5. Выводит:
   - Точность на тестовой выборке.
   - Результаты 5-кратной кросс-валидации.
